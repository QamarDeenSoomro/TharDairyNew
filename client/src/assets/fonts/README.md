# Fonts Directory

This directory contains custom fonts for the application.

## MBSindhWeb Font
Please upload the MBSindhWeb font files in the following formats:
- MBSindhWeb-Regular.woff2
- MBSindhWeb-Regular.woff  
- MBSindhWeb-Regular.ttf
- MBSindhWeb-Bold.woff2
- MBSindhWeb-Bold.woff
- MBSindhWeb-Bold.ttf

These fonts will be automatically loaded for Sindhi language support with proper RTL layout.
